# 符文前线 · 塔防

一个无需安装依赖、打开浏览器即可游玩的单页塔防小游戏。游戏采用纯粹伤害、四类防御塔、六维成长与技能石链接/光环机制。

## 开始游戏

打开 `index.html` 即可游玩。选择塔的类型后点击地图空地建造；点击已建防御塔可编辑 4 个辅助石链接槽，或用右侧“替换”按钮更换塔型。右键拆塔返还 60% 碎片，空格开始下一波，可切换 1×/2× 游戏速度。

## 开发机制与实现清单

### 纯粹伤害与防御

- [x] 法术、箭矢、召唤物和持续伤害统一调用 `damage()`；没有元素伤害或物理/法术抗性。
- [x] 怪物只有 `def` 防御属性；伤害公式为 `实际伤害 = 原始伤害 × (1 + 易伤%) × K / (K + def × (1 - 破防%))`，其中 `K = 90 + 6 × 波次`。
- [x] 易伤按乘法加成，破防只削减 `def`；所有增伤与频率乘法使用软上限，防止无上限滚雪球。

### 防御塔与辅助

- [x] **弓（arch）**：高速攻击多个目标；攻击频率与直击增伤提升箭矢输出。
- [x] **法术（spell）**：包含追踪、范围、减速和连锁攻击；法术施法频率、直击与 DoT 增伤均有效。
- [x] **召唤（summon）**：物理刃灵继承攻击频率，法术奥灵继承施法频率；召唤塔自身按施法频率召唤。
- [x] **辅助（support）**：不攻击。强化光环塔强化范围内友方塔的六维；剧毒、冰霜光环只对怪物施加 debuff，也可链接辅助石。
- [x] 辅助技能石最多链接 4 颗，同名最多 2 颗；第二颗按 ×1.35 计入。范围、施法/攻击频率、直击、DoT、破防及怪物 debuff 均有对应辅助石。
- [x] 光环塔占地；覆盖中心效果为满值，边缘为 55%，最多叠加 `AURA_CAP=3` 座。剧毒光环可链接 DoT 辅助石强化中毒；链接与光环增益合并后经过软上限。

链接石示例：集中效应（范围 -25%、伤害 +35%）、范围扩张（范围 +30%、伤害 -20%）、施法急速（施法 +40%）、召唤增幅（施法 +40%、召唤上限 +1）、攻击急速（攻击 +40%）、连射校准（攻击 +20%、额外箭矢）、强力打击（直击 +45%）、破防之刃（无视防御 25%）、毒素蔓延（DoT +70%），以及腐蚀之牙、破甲印记、冰霜缠绕、纠缠藤蔓、精神洞穿、余烬附着等 debuff 石。

- [x] 元素种子只由直接命中触发，不会由燃烧、中毒等持续伤害触发：火之种有 50% 几率点燃 3 秒，每秒造成该次命中伤害的 20%，最多叠加 5 层；冰之种有 50% 几率冰冻 3 秒并使其受到的伤害提高 10%；雷之种有 50% 几率感电 3 秒，感电目标被命中时释放最多 3 次连锁闪电，每次造成施加感电那次命中伤害的 50%。

### 六维成长

- [x] **作用范围**：改变输出塔的反应半径，也用于光环覆盖半径。
- [x] **施法频率**：作用于法术和召唤动作，并作用于法术召唤物。
- [x] **攻击频率**：作用于弓塔与物理召唤物。
- [x] **直击增伤**：强化统一的纯粹直击伤害。
- [x] **DoT 增伤**：强化燃烧、中毒等持续伤害。
- [x] **对怪物 debuff**：支持减速、破防、定身、燃烧、中毒与易伤效果。

强化光环每座在覆盖范围内为上述六维提供最多 12% 增益，按中心满值、边缘 55% 衰减；多座光环最多取效果最强的三座。增益软上限对合计加成 `x` 采用平滑曲线：`x ≤ 1` 时为 `x`，更高时为 `1 + 0.5 × (1 - exp(-(x - 1) / 0.5))`，最终趋近 +150%。辅助塔造价约为常见输出塔的 30–40%；平衡目标为单座光环覆盖约 35 座输出塔时才值得建造。

### 平衡锚点

- [x] 开局 150 碎片、20 生命；普通怪生命按 `max(90, 90×(w-1) + 26×(w-1)^1.6)` 计算，防御为 `14 + 4.2w`。
- [x] 怪物速度从约 `0.07 格/秒` 起逐波增加并封顶；每波约 8 只，之后每波增加 3 只，分批生成。
- [x] 普通击杀奖励 6 碎片，精英更多；清波奖励 `32 + 9w` 碎片。
