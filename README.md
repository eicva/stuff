# 符文前线 · 塔防

一个无需安装依赖、打开浏览器即可游玩的单页塔防小游戏。灵感来自动作 RPG 的主动技能石与辅助技能石链接机制。

## 开始游戏

打开 `index.html` 即可游玩。选择主动技能石后点击地图空地部署防御塔；可选最多两颗辅助技能石链接到之后部署的塔。点击“开始第 1 波”迎击敌人。

## 技能

- 奥术飞弹：追踪单体投射物
- 烈焰爆弹：爆炸范围伤害
- 寒霜脉冲：对敌人减速
- 闪电链：高伤害电弧
- 刃灵召唤：近战快速攻击
- 辅助石：多重投射、急速施法、强力打击、远距增幅、余烬附着

右键防御塔可拆除并返还部分碎片；空格键开始下一波；可切换 1×/2× 游戏速度。
